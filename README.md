## Projects

### Aria (Serverless AI Assitant)
A cloud hosted Ai assistant created using open souce models to bring users recent updates on world events, this is a all rounder Ai assitant, that is capable of handling coding work(I use it as to work on it), and its capable of keeping you up to date on new events.

### EasyTask (Serverless TaskManager)
A full-stack task management application that can be used in teams where everyone need to see the tasks that need to be complete, thi swas built using Cloud tools, from hosting the Web server to deloying the Frontend and hosing the Databse as well, everything is cloud.

### Community Portal Website (Full stack)
Full-stack web application that connects users through alerts, announcements, and a complaint system with secure admin and super admin panels, built using different Cloud services to try and create a smoooth experiencefor users.

### Azure SQL Migration Project
Migrated a local SQL Server database to Azure SQL Database and connected it to applications and SSMS successfully.

### Azure CI/CD Monitor (DevOps)
Developed a Website that monitors my GitHub deployment pipelines for another website(a solution for one of my other projects).

### AWS Static Website
A Static portfolio hosted on a Aws s3 bucket, I integrated a CI/CD deployment pipeline, To eliminate the need of having to manually update this website, everthing is automated.
